🎓 College Event Hub – Event Management System

📌 Project Description

College Event Hub is a web-based application developed using HTML, CSS, and JavaScript. It helps students view college events and register for their favourite events easily.

🎯 Objectives

- Display college events with details.
- Search and filter events.
- Register for college events.
- Validate student registration details.
- Prevent duplicate registrations.
- Track and cancel registrations.
- Store information using Local Storage.

✨ Key Features

- 🎉 Dynamic Event Display
- 🔍 Search and Filter Events
- 📅 Event Date and Category
- 📝 Student Registration Form
- ✅ Form Validation
- 🚫 Duplicate Registration Prevention
- 👥 Event Seat Capacity Management
- 📋 My Registrations
- ❌ Cancel Registration
- 💾 Local Storage Support
- 📱 Responsive Design

🛠️ Technologies Used

- HTML – Webpage structure
- CSS – Design and styling
- JavaScript – Functionality and validation
- Local Storage – Save data in the browser

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Browse events and register using the form.
